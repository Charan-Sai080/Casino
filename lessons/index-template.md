# Standard Lesson Template (Book Index)

Every technology "book" in this folder must follow this exact structure to ensure you have a comprehensive, interview-ready reference guide.

## 1. Introduction
- What is this tool?
- A simple, intuitive analogy for how it works.
- Where does it fit in the modern tech stack?

## 2. Why We Use It
- What problem does this solve?
- What did engineers do before this tool existed?
- What are the primary benefits for a business or engineering team?

## 3. How It Works Internally
- High-level architecture (the core engine, daemons, APIs).
- Key concepts and vocabulary (e.g., Images, Containers, Volumes).
- The underlying operating system or network mechanics it relies on.

## 4. Real-Life Scenarios & Behaviors
- **Scenario A: Local Development** - How developers use it on their laptops.
- **Scenario B: CI/CD & Testing** - How it behaves in automated pipelines.
- **Scenario C: Production Scale** - How it handles traffic, scaling, and high availability.
- **Scenario D: Failure & Recovery** - What happens when it crashes, loses power, or faces bad configurations, and how it recovers.

## 5. Interview Cheat Sheet
- Top 3 questions recruiters/engineers will ask about this tool.
- Keywords you must mention in an interview.
